# LinkSwift 疾风文件夹版（实验版）

修改日期：2026-10-10。基于 hmjz100/LinkSwift 1.1.3，保留上游作者标注，AGPL-3.0-or-later；完整可编辑源码在 LinkSwift-Surge-Folders.user.js，许可证在 LICENSE。
上游：https://github.com/hmjz100/LinkSwift

## 安装
1. 退出旧版疾风并打开 build/疾风下载.app（0.4.0）。任务数据不删除。
2. 油猴管理面板 → 实用工具 → 从文件导入，选择 LinkSwift-Surge-Folders.user.js；查看权限后确认安装。
3. 暂停旧 LinkSwift 和「网盘直链下载助手」，仅启用文件夹版；原脚本保留，便于回滚。
4. 新脚本使用独立身份，不复制原脚本密钥。按疾风「LinkSwift 网盘推送」页面配置 Aria2；存储路径留空。
5. 刷新夸克，选中一个小文件夹，下载助手获取链接。确认展开的文件数，再选择 Aria2 推送。

## 范围
- 夸克个人网盘与分享页的选中文件夹递归枚举、分页、继承页面已有分享令牌；仅使用当前登录权限。
- 相对路径作为 out 传给疾风 0.2.2 及以上；保存于用户选择的根目录，不允许绝对路径、.. 或现有符号链接。
- 同名文件处于不同子目录时分别保存；已存在文件由 aria2 自动改名，不覆盖。
- 空文件夹不单独创建；最多 32 层、20000 项；接口失败停止展开，避免把部分列表当成完整列表。
- 此版本的目录路径适配仅针对疾风 Aria2；不要将目录结果用于其它下载器/命令导出。
- 已完成模拟目录分页测试和本机真实 HTTP 下载测试；夸克在线目录接口兼容性及实际文件下载尚需安装后验证。访问受限、接口变化、直链过期会报错，不承诺不限速。
- 不要分享脚本调试日志、Cookie、签名直链或本机密钥。

## 构建
folder-core.js 为纯遍历模块，build_variant.py 在原版源码上应用修改；生成的完整 userscript 本身即可审阅、编辑和安装，不依赖构建环境。
